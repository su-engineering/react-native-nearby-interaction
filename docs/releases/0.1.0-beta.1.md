# 0.1.0-beta.1

First beta of `@su-engineering/react-native-nearby-interaction` for iOS UWB
accessories. Initial physical distance ranging, stop/restart, foreground resume
and tag reconnection were validated on an iPhone 16 Pro / iOS 27.0 with a
Truesense T-TAG. Direction and angle were unavailable in the tested sessions;
other accessories and the remaining hardware acceptance matrix are unverified.

```sh
npm install @su-engineering/react-native-nearby-interaction@next
```

Includes configurable Truesense T-TAG BLE profiles and framing, external
transports for other Apple-compatible accessories, typed events and a React
hook, nullable distance/angle/direction, bounded recovery, acknowledged writes,
write cancellation and stale-reading cleanup.

Compatibility target: React Native 0.83.x (baseline 0.83.1), React 19.2.x,
Expo SDK 55 (baseline 55.0.0), iOS 15.1+. Automated checks include fresh tarball
installation/bundling, Swift protocol tests and iOS simulator builds. Refer to
the linked release commit's CI results for the actual build outcome.

Android, iPhone-to-iPhone, concurrent tags and background ranging are outside
this beta. MTU chunking is opt-in and requires firmware reassembly support.

MIT licensed. See the README for setup and docs/validation/2026-09-21.md for
the hardware evidence, fixes and remaining acceptance tests.
